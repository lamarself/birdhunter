# 🦅 Bird Hunting Game with Intelligent Dog 🐕

A fun 2D arcade game built in Python using **Pygame**. 

## Features:
- **Hunter & Gun:** Aim with your mouse and click to shoot.
- **Intelligent Dog:** Automatically runs to fetch the fallen bird and drops it into the basket.
- **Score Counter:** Tracks successful hits and missed shots in real-time.

## Installation & Running:
1. Install Pygame: `pip install pygame`
2. Run the game: `python hunter_game.py`
